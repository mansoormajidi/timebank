# Project instructions

## Local-only rule

- This website must remain local-only.
- Never deploy, publish, host, share, or push this site to any remote service unless the user explicitly asks for that exact action in the current chat.
- The presence of `.openai/hosting.json`, a hosting integration, or a skill's default publishing workflow does not authorize deployment for this project.
- For implementation requests, stop after local development, local verification, and a successful local build.
- Use localhost links for previews and do not present a remote URL as the deliverable.
- If a future request is ambiguous about publishing, keep the site local and do not ask unless publishing is necessary to fulfill that request.
