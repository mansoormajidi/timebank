# همراه‌بانک — Home / Light

پروتوتایپ صفحهٔ خانه بر اساس node `343:14591` فایل Figma Authentication.

## اجرا

```sh
npm install
npm run dev
```

برای کنترل خروجی: `npx tsc --noEmit` و `npm run build`.

## محدوده

فقط صفحهٔ Home پیاده‌سازی شده است. موجودی، شماره‌ها، فعالیت‌ها، کارت، کمپین و نمودار همگی نمایشی هستند. هیچ API بانکی، ورود واقعی، پرداخت یا ذخیرهٔ اطلاعات شخصی وجود ندارد. مسیرهای آینده با پنجرهٔ توضیحی مشخص‌اند.

- React + TypeScript، Tailwind CSS 4 و Motion (`motion/react`).
- چیدمان RTL، فونت محلی Vazirmatn، کنترل با صفحه‌کلید، Escape و مدیریت فوکوس پنجره‌ها.
- نوار پایین با `layoutId` مشترک، فنر کوتاه و واکنش لمس؛ رفتار الهام‌گرفته از Instagram است و تطابق فریم‌به‌فریم ادعا نمی‌شود.
- پشتیبانی از ترجیح کاهش حرکت و اندازهٔ موبایل؛ قاب ۴۰۲ پیکسلی در دسکتاپ مطابق عرض Figma.
- تمام تصاویر و آیکن‌های صفحه از فایل اصلی Figma صادر و محلی ذخیره شده‌اند. چند آیکن به دلیل در دسترس نبودن خروجی برداری، به صورت PNG اصلی Figma ذخیره شده‌اند.
- Yekan Bakh در طرح مرجع ذکر شده اما فایل مجاز فونت همراه آن نبود؛ برای تطابق نهایی می‌توان فونت دارای مجوز را جایگزین کرد.

## ساختار قابل توسعه

- `app/page.tsx`: ترکیب بخش‌های Home و وضعیت‌های محلی.
- `components/BottomNavigation.tsx`: ناوبری و انتقال گزینهٔ فعال.
- `components/BottomSheet.tsx`: پنجرهٔ جزئیات با مدیریت فوکوس.
- `components/HomeDetails.tsx`: جزئیات نمایشی Home و جایگاه سرویس‌های آینده.
- `components/Icon.tsx`: دارایی‌های اصلی Figma.
- `lib/demo.ts`: داده‌های نمایشی؛ در آینده با لایهٔ service جایگزین شود.
- `app/globals.css`: رنگ‌ها، سطوح شفاف، فاصله‌ها و قواعد واکنش‌گرا.

صفحات Login، Transfer و سرویس‌های اوقاف باید به صورت مسیرهای مستقل اضافه شوند؛ وضعیت نمایشی حساب را به عنوان مدل واقعی بانکی استفاده نکنید.

## تبدیل Dark به Light

ترتیب محتوا، هدر بلند، اکشن‌های گرد، بنر PS5، کارت سبز، تصاویر وقف/هدایا و نوار شناور حفظ شده‌اند. پس‌زمینهٔ تیره به خاکستری روشن، سطح `#293352` به سفید نیمه‌شفاف، متن روشن به `#131E3C` و تأکیدها به `#C2986B` تبدیل شده‌اند. بافت زمینه همان خروجی Figma با فیلتر CSS است. تغییرها شامل کنتراست روشن، توضیح نمایشی بودن داده‌ها و کنترل‌های قابل تعامل است.

## اعتبارسنجی و محدودیت

TypeScript، ساخت خروجی و پاسخ HTTP محلی بررسی شده‌اند. بسته‌های قالب به نسخه‌های اصلاح‌شده ارتقا یافته‌اند؛ گزارش نصب نهایی ۰ آسیب‌پذیری شناخته‌شده اعلام کرد (۳۱ اوت ۲۰۲۶). آزمون بصری/تعامل خودکار مرورگر انجام نشده است. قبل از هر استفادهٔ عملیاتی، بررسی امنیت وابستگی‌ها، تست دسترس‌پذیری و طراحی/اتصال سرویس‌های واقعی لازم است.
