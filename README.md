# تایم‌بانک — پروتوتایپ محلی

نسخهٔ روشن Home، ورود، ثبت‌نام و انتقال وجه، با React، TypeScript، Tailwind CSS و Motion. هیچ API بانکی یا سرویس احراز هویت واقعی به برنامه متصل نیست.

## اجرا

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 3000
```

آدرس محلی: http://localhost:3000

- شروع برنامه: اسپلش متحرک؛ یک ثانیه پس از پایان ورود اجزا، فرم ورود در باتم‌شیت ظاهر می‌شود. ورود و ثبت‌نام از پروفایل Home نیز در دسترس‌اند.
- دکمهٔ «استفاده از اطلاعات آزمایشی» فرم را پر می‌کند. رمز نمونه: `Time1234`؛ کد تأیید نمونه: `123456`.
- دوربین فقط پس از درخواست کاربر فعال می‌شود. عکس با دوربین پشت (در صورت وجود)، ویدیو با دوربین سلفی و صدا، به مدت پنج ثانیه ضبط می‌شود.
- عکس‌ها و ویدیوها فقط در حافظهٔ مرورگر می‌مانند؛ هیچ آپلود یا ذخیرهٔ دائمی انجام نمی‌شود. ترک فلو یا پنهان شدن صفحه، دوربین را خاموش می‌کند.
- انتقال وجه، کارمزد، موجودی، استعلام گیرنده، پیامک، تأیید هویت و گزینهٔ ورود سریع همگی نمایشی‌اند. ورود سریع سنسور بیومتریک را فعال نمی‌کند.
- اسکن کارت، OCR واقعی نیست؛ سریال نمونهٔ قابل ویرایش `1G234245` را پر می‌کند. تاریخ تولد انتخاب‌گر شمسی دارد.
- رمز دوم در جزئیات کارت، رمز پویای شش‌رقمی با اعتبار ۳۰ ثانیه است. خودکار عوض می‌شود و قابلیت کپی دارد؛ تا پایان اعتبار، در انتقال نمایشی همین صفحه نیز پذیرفته می‌شود. این رمز در بانک واقعی کاربرد ندارد.
- فعالیت‌های تکمیل‌شدهٔ انتقال، کمک، وقف و مدیریت کارت در مرورگر ذخیره می‌شوند و با تازه‌سازی باقی می‌مانند. رمز، اطلاعات ثبت‌نام و فایل‌های دوربین ذخیرهٔ دائمی نمی‌شوند.

## طراحی

رنگ‌های اصلی `#131E3C` و `#C2986B`، سطوح روشن با blur، RTL و فونت متغیر محلی Vazirmatn حفظ شده‌اند. اینپوت مشترک متریال بدون placeholder است؛ label با فوکوس یا داشتن مقدار بالا می‌رود. Home ورود اختصاصی نرم، هدر ثابت و نوار پایین شیشه‌ای دارد. انتقال وجه از زمینهٔ رنگی و کارت‌های سفید سایه‌دار با همان رنگ‌های برند استفاده می‌کند. دکمهٔ سکندری بدون پس‌زمینه و با حاشیه است؛ فاصلهٔ جفت دکمه‌ها ۱۶ پیکسل است. کل کارت‌های PS5 با موس یا لمس، حلقه‌ای در هر دو جهت جابه‌جا می‌شوند؛ بستن هر بنر فقط همان بنر را حذف می‌کند. باتم‌شیت‌ها تا پایین قاب می‌آیند و روی ناوبری قرار می‌گیرند. اعداد ورودی فارسی نمایش داده می‌شوند و فارسی، عربی و انگلیسی پذیرفته می‌شوند.

مرجع Figma در فایل Authentication، کلید `mwKnc5562UPtBi4r4ta0y0`:

- اسپلش: `74:191`
- Home: `343:14591`
- ورود: `319:522`
- ثبت‌نام: `104:529`
- انتقال وجه: `358:16177` (چیدمان فشردهٔ آبانک با رنگ‌های تایم‌بانک؛ روش انتقال در باتم‌شیت)

آیکن‌های خدمات، قبض، اجاره‌نامه، ریال، رمز، کد ملی، هویت، سلفی، پل، پایا و ساتنا عین فایل‌های ارسالی‌اند. انیمیشن موفقیت از `Check.lottie` استخراج شده و با Lottie نمایش داده می‌شود. فایل‌های Face ID و biometric authentication و آیکن‌های نور، چهره، ماسک و محیط آرام نیز عین فایل‌های ارسالی هستند. آیکن کپی از مجموعهٔ محلی Unicons است؛ مجوز همراه آن در `public/assets/copy-LICENSE.txt` نگه داشته شده است. سایر دارایی‌ها از طراحی Figma گرفته شده‌اند. فایل دارای مجوز Yekan Bakh در دسترس نبود؛ Vazirmatn استفاده شده است.

## ساختار

- `app/page.tsx`: Home و جابه‌جایی میان فلوهای نمایشی.
- `components/MaterialField.tsx`: فیلد متریال، لیبل شناور، خطا و نمایش/پنهان‌سازی رمز.
- `components/FlowShell.tsx`, `OtpField.tsx`: قاب مشترک و کد تأیید.
- `components/AuthFlow.tsx`, `SplashScreen.tsx`, `BirthDatePicker.tsx`: اسپلش، ورود و ثبت‌نام.
- `components/CameraCapture.tsx`: ضبط محلی و پخش ویدیو با اصلاح مدت WebM و عنصر مستقل از دوربین زنده.
- `components/SuccessAnimation.tsx`, `AuthAnimation.tsx`: انیمیشن‌های ارسالی.
- `components/CardOtpPanel.tsx`, `lib/card-otp.ts`: رمز پویای محلی با تایمر و انقضا.
- `components/RecipientAvatar.tsx`: آواتار دوحرفی با رنگ ثابت برای هر مخاطب.
- `components/TransferFlow.tsx`, `lib/transfer.ts`: انتقال و محدودیت‌های نمونه.
- `components/PromoCarousel.tsx`: درگ و اسلاید کل کارت.
- `components/HomeDetails.tsx`, `GivingForm.tsx`, `CardActions.tsx`: جزئیات، مدیریت کارت و مشارکت نمایشی.
- `lib/activity.ts`: ثبت و نگهداری محلی فعالیت‌های تکمیل‌شده.

## کنترل کیفیت

```sh
npx tsc --noEmit
npm run build
node work/check-flows.mjs
```

ورودی‌های فارسی/عربی، مرز موجودی و کارمزد، نوع مقصد، ورود، ثبت‌نام با عکس و ویدیوی واقعی مرورگر، و انتقال نمایشی تا رسید بررسی شده‌اند. این پروژه برای استفادهٔ بانکی واقعی آماده نیست؛ پیش از اتصال واقعی به طراحی امنیت، سرور، اعتبارسنجی هویت، نگهداری امن داده و بررسی کامل دسترس‌پذیری نیاز دارد.
